# Epic context packs

These files are short, task-oriented re-entry packs for fresh-session Codex work.

## Purpose

A context pack tells the agent:
- which invariants matter most for the epic,
- which authoritative contracts/schemas to load,
- which pattern cards are worth reading,
- which failure modes and tests to keep in mind.

## How to use

1. Read `AGENTS.md`.
2. Read `docs/status/CURRENT_FOCUS.md`.
3. Read the relevant epic file under `docs/planning/epics/`.
4. If a matching context pack exists here, read it next.
5. Read the referenced pattern card(s) only.
6. Open long source notes only if the task directly touches that subsystem.

## Important rule

Context packs are **routing aids**, not peer authorities.

If a context pack and an authoritative workflow/architecture doc ever disagree, the authoritative doc wins and the context pack must be updated.
