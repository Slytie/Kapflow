# Dispatch reporting examples

These examples are grounded in uploaded EOS material.

Current families in the repo:
- **2026-03-03 baseline examples** (`eos_route_rows_example.yaml`, `normalized_actuals_example.yaml`, `upd_candidate_example.yaml`)
- **2026-03-16 QDCI/DVC4 partial examples** added for `EPIC-120` frontend workpage prototyping

The 2026-03-16 examples are intentionally **partial**:
- they exist to keep the EOD workpage prototype aligned with one consistent summary/date/source family,
- they are suitable for frontend mapping/render tests,
- and they do **not** claim full canonical row coverage of the source workbook.
