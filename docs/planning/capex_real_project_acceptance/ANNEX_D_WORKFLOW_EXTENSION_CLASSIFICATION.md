# Annex D - Workflow Extension Classification

This annex classifies real-project subject-matter workflows without expanding
MVP scope silently.

| Workflow | Classification | Implementation note |
|---|---|---|
| Scope Management | MVP / early | Required for scope-level closure and false-closure prevention. |
| Budget & Commercial Control | MVP / early | Observation and reconciliation, not ERP replacement. |
| Safety & Work Permit Readiness | MVP / early | Standard CAPEX readiness; not K3-only. |
| Commissioning / Start-up | MVP / early | Separate from production release and closure. |
| Production Release | MVP / early | Operator acceptance and effectiveness gate. |
| Maintenance Handover | MVP / early | Maintenance plans, spares, training, documentation, lifecycle obligations. |
| Shutdown / Schedule Planning | MVP-lite / conditional | Add minimal schedule / production-impact fields if SME marks mandatory. |
| Supplier Claim / Warranty | Post-MVP reserved | MVP preserves commercial-not-technical separation. |
| Lessons Learned / After-Handover Performance | Post-MVP reserved | Reserve recurrence and performance feedback hooks. |
