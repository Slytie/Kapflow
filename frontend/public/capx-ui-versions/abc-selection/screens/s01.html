S01 — New project intake

Start a new CAPEX request and identify whether the request is a solution-shaped ask or an underlying business need.

Persona: Project manager

Task: Create the request, preserve the business need separately from proposed solution, identify missing evidence, and prepare feasibility review.

Design A expected signal

Strong if intake form and project object page are clear; may feel form-heavy.

Design B expected signal

Can show request node and goal node, but may be too abstract for initial data entry.

Design C expected signal

Expected to perform best: protocol guides intake, evidence, ownership, and next step.

Observer prompts

Can the participant identify official state, evidence basis, stale trigger, blocker, and next action?
