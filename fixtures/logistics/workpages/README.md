# Logistics workpage v0 fixtures

These fixtures are **planning/test fixtures** for the first frontend workpage tranche.

They are:
- human-authored examples,
- derived from repo-native normalized workflow examples plus the workpage product brief,
- and intentionally **not** canonical runtime truth.

Use them to:
- freeze the intended `WorkpageViewModel` shape,
- drive frontend mapping tests,
- and keep early workpage FE development grounded in repo-native source.

Do not treat these fixtures as:
- artifact versions,
- backend API payload contracts,
- or authoritative workflow outputs.

They are also intentionally **different** from `fixtures/frontend_contracts/`:
- `fixtures/frontend_contracts/` are backend-owned generated API contract snapshots,
- `fixtures/logistics/workpages/` are human-authored planning/test fixtures for the first workpage FE slice.
